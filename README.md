Full-Stack Image Gallery Application
​A full-stack web application designed for image uploading, media management, and organized grid viewing built with modern web technologies.
​Institution: University of Gujrat
​Tech Stack
​Frontend: React JS (with Vite)
​Backend: Node.js with Express
​Database: MongoDB with Mongoose
​Features
​Image Upload: Seamless file upload interface to store and manage images.
​Gallery Grid View: Responsive layout to display uploaded pictures and media files cleanly.
​Database Integration: Secure storage and retrieval of image records using MongoDB.
​Getting Started
​Clone the repository
​Run npm install in both client and server directories
​Configure your environment variables (.env)
​Run npm run dev to start the application
